# OpenDPD Studio 2.3.0

DPD Arena is built around **APA_200MHz_b**, the 200 MHz, 256-QAM measured capture. **Rank**, **Submit** and **Rules** use this one dataset. The release includes **23 model entries, 83 configurations and 233 test cases**, based on **218 independently fitted checkpoints**. Other datasets are outside the Arena catalogue, results and packaged capture assets.

## Results and Pareto fronts

Rank compares each backbone and parameter configuration using complete-symbol **EVM**, emitted-output **ACLR**, real parameters and arithmetic operations per output IQ sample. Four interactive plots show EVM and ACLR against parameters and operations; diamonds highlight each plot's Pareto front and error bars report variation across seeds. Budget filters include all configurations that fit the selected cap.

```text
Q = mean over seeds of 0.5 × (ΔEVM + ΔACLR)
FoM = Q − 5 log10(P / 1000) − 5 log10(OPs / 2000)
```

The same cost references apply to every size. Smaller models score higher at equal linearization. Only DPD costs count. Output power must stay within ±0.5 dB and mean quality must be positive to rank. Offline and stateful execution, and official and workspace results, have separate comparisons.

## Frozen PA and test-only evaluation

Every DPD uses one validation-selected **TRes-GRU PA with 4,871 parameters**. PA and DPD training, validation and test inputs come from disjoint slices of the original APA_200MHz_b capture. The held-out test set contains complete OFDM symbols. Cascade outputs are predictions from this frozen PA, not new predistorted hardware measurements.

Each neural configuration receives **240 complete epochs**, all stride-1 200-sample windows, batch 64 including the tail, and three seeds. This is 94,320 optimizer updates per seed. Validation alone selects weights; all fitting finishes before test evaluation. Only test EVM, ACLR and power checks determine final scores and ranks. MP/GMP least-squares methods use training-only PA feedback, never ILC targets. ILC remains outside Arena.

The APA B result bundle is a checked subset of the completed v6 experiment. Its weights, raw test observations and scores are unchanged. The full historical experiment remains archived, and the new public protocol is `dpd-arena-v6-apa-b`.

## Studio and hosted execution

The release also includes [safe backbone templates](../architecture/user-backbones.md), [classical PA fitting](../performance/pa-identification-comparison.md), parameterized custom DPD submissions and isolated [hosted Arena execution](../guides/arena-hosted.md). Workspace submissions do not publish a global leaderboard entry. Previous protocol records remain available as evidence without entering current ranks.

The custom waveform inputs and import, session, export and GPU-boundary protections from 2.2.17 and 2.2.18 are retained. CPU and CUDA execution share the scientific recipe; execution acceleration does not reduce training budgets.
