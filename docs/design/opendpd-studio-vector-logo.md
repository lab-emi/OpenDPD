# OpenDPD Studio vector identity

The production identity is transparent SVG artwork, replacing the generated raster draft at the user's request on 2026-09-12. The circular O and circuit terminals are geometric arcs/circles; the waveform uses smooth cubic Bézier curves. Rounded stroke joins and consistent stroke widths keep the symbol clear at navigation size.

Assets:

- `frontend/src/assets/opendpd-studio-logo.svg`: navy/blue/teal wordmark for light surfaces, viewBox 600×168. The signal stroke uses `#008FAC` to remain clear on white.
- `frontend/src/assets/opendpd-studio-logo-inverse.svg`: the same geometry with light lettering and brighter blue/cyan for dark surfaces, viewBox 600×168.
- `frontend/src/assets/opendpd-studio-mark.svg`: square emblem for the compact dark navigation, viewBox 160×160. It uses its own viewport, without cropping the wordmark.
- `frontend/src/assets/opendpd-studio-mark-light.svg`: matching square emblem for the compact light navigation, viewBox 160×160.

`StudioLogo` selects the appropriate full or compact artwork from the active MUI palette in both the navigation and About page. The palette follows `prefers-color-scheme`, including changes while Studio is open. There is no bitmap inversion, CSS filter, external font request or per-frame image processing. The favicon uses the same emblem with an internal system-color-scheme media query.

Every visible element is a path or circle. The files contain no raster image, background rectangle, white knockout mask, filter, script, external font or external resource reference. Letter counters and circuit terminal holes remain transparent. The Studio logo has no backing plate; the separate EMI Lab and TU Delft artwork retains its official colors on light brand plates.

The lettering is outlined **Manrope**: weight 750 at 88 units for OpenDPD with −1.4 units of tracking; weight 650 at 28 units with 8 units of tracking for STUDIO. Converting the lettering into paths makes its geometry independent of installed fonts and web-font loading. Coordinate precision is 0.001 units. The emblem uses a 9-unit ring and 5-unit signal/circuit strokes.

Font provenance: [Google Fonts, Manrope](https://github.com/google/fonts/tree/8f9a401dbb3793e0d1264b15d96aa253f05280f5/ofl/manrope), font SHA-256 `d0639be45d0af36e798172419d7bd173c4bd4f29e2b76cbb69db1d11bf8b0a40`. The SIL Open Font License and copyright notice are retained in `frontend/src/assets/LICENSE-Manrope.txt`; the upstream font log is retained in `frontend/src/assets/NOTICE-Manrope.txt`. The font binary is not shipped or downloaded by the app.

The previous [image generation prompts](opendpd-studio-logo-prompt.md) remain as design history. This production SVG revision was constructed as vector geometry with font outlines, not generated by a raster image model. The original generated PNG remains in the image-generation output directory; its redundant application asset has been removed.
