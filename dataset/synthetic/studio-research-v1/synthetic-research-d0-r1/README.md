# OpenDPD dataset contribution

Origin: **synthetic**. Samples: **16384**. License: **CC0-1.0**.

See `dataset.json` for the contributor's description, attribution, signal metadata, split and hashes. `data.csv` has finite I_in,Q_in,I_out,Q_out values; preprocessing is raw-v1.

Synthetic data demonstrate software behavior and are not physical RF measurements. A contributor's measured declaration is not independent certification.

Inclusion requires human review of data, rights and provenance. No automatic merge is requested. Questions: emi.lab@outlook.com.
